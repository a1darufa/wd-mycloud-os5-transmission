Login and access

Transmission created a random password at its first start. Set your own here; the saved random one is then deleted.

At least 8 characters. Only a salted hash is stored, as Transmission itself does. For apps and the web interface; 1024 to 65535. The default is 9091. One pattern per line, such as 192.168.1.*: * and ? are wildcards and [0-9] is a range. CIDR such as /24 doesn't work here. The defaults allow private home networks and Tailscale. The NAS itself is always allowed, and the login is required from every address.
Saving restarts Transmission, which takes a few seconds; transfers resume on their own.
